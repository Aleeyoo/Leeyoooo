# X 上的 左子祯：”AI 时代的个人网站是什么样子？” / X

https://x.com/zuozizhen/status/2033784623864680927?s=20

你现在的个人网站，本质上是一张贴在互联网上的名片。

别人扫一眼，点头，关掉，忘掉。

Agent 时代的个人网站不是名片。它应该是你放在互联网上的一个活的自己，能对话、能干活、能替你谈生意、能在你睡觉时帮你筛掉 90% 的噪音，把那 10% 的金子递到你枕边。

**你不是在“展示自己”。你是在部署自己。**

———

## 一个根本性的思维转换

传统网站是货架：我把信息摆在这里，你自己看，你来挑。

Agent 时代完全反过来：你带着意图来，我的系统主动理解你、服务你、对接你。

有人凌晨三点访问你的网站，你的 Agent 跟他聊了 20 分钟，判断这是一个高质量合作机会，自动收集了需求文档，排好了你明天的日程，给你发了一条摘要。你早上醒来，直接进入正题。

这不是科幻。这是终局。

———

## 传统结构 vs 终局结构

![图像](https://pbs.twimg.com/media/HDl0MxPbEAE0cIk?format=jpg&name=large)

传统网站的每个模块都是名词：一个页面、一堆文字。

终局形态的每个模块都是动词：一个过程、一个系统、一个持续运行的东西。

你的网站不是一个地方。它是一个过程。

———

## 6 个模块的终局形态

**1\.** **🧠** **My OS — 取代 About Me**

“我是一个热爱技术的全栈开发者，擅长 React，喜欢开源。”

**等于什么都没说。**

在 Agent 时代，技能可以被 AI 平替，思维方式不能。

所以不要写自我介绍。把你的操作系统跑起来。

来访者不是来“读”你的，是来“体验”你的。他们可以直接和你的 OS 对话，输入一个决策场景，比如“该不该现在辞职做独立开发”，你的思维模型基于你的信念体系、决策框架、过往经验给出分析路径。不是给答案，是让人亲眼看到你的脑子怎么转的。

未来最贵的不是你的技能清单，是你的认知源代码。

技能是编译后的产物，别人看到的是同样的输出。

源代码才是不可替代的东西。

———

**2\.** **⚡** **Playground — 取代 Portfolio**

传统作品集：三张截图，一段描述，一个 GitHub 链接。来访者看完想的是“嗯，还行”，然后关掉。

问题在于，Portfolio 需要来访者自己想象你能为他们做什么。

Playground 让他们直接体验。

- **你是设计师？** 来访者上传一张产品截图，你的审美模型当场给出评分、改进方案、三个改进版本的 mockup，附带你的设计哲学，“我为什么把这个按钮移到这里”。
- **你是程序员？** 来访者描述一个需求：“我想做一个会员订阅系统”，你的 Agent 用你的架构思维拆解它——技术选型、数据模型、关键决策点、估时、风险点。来访者看到的是“他怎么思考一个系统”。
- **你是数据分析师？** 来访者上传一份 CSV，你的分析 pipeline 自动跑一遍，输出关键发现、可视化图表、建议行动。

终局的 Playground 应该是持续进化的：每一次来访者的交互都在训练它。有人上传了一种你没处理过的设计风格，你的 Agent 学到了新的审美。有人提了一个你没想过的架构问题，你的拆解框架变得更完整。你的 Playground 越用越强，它不是一个静态的 demo，是一个越来越像你的能力分身。

而且它会主动出击。当它发现来访者的需求和你的能力高度匹配时，它不只是展示结果，它会直接说：“这个需求很适合他，要不要我帮你生成一份合作提案？”从能力展示到商业转化，一步完成。

> 作品集是尸检报告，对已经完成的东西做事后分析。Playground 是活体演示，让人直接感受你的能力在运转。

———

**3\.** **🌊** **Thinking Feed — 取代 Blog**

博客的根本问题不是“写起来太慢”。是它线性、孤立、死的。每篇文章是一个孤岛，读者看不到你的知识结构。写完就不变了，但你的认知在持续进化。

终局的 Thinking Feed，你甚至不需要“写”。

你在 GitHub 提交了一段代码，Thinking Feed 自动生成一条技术笔记。你在微信读书上划了一条线，它自动变成一条读书碎片。你和朋友的一段语音对话里冒出了一个好想法，它被自动捕捉、转录、归类。你的日常行为本身就是内容源，Thinking Feed 是一个永远在运转的思想捕捉网。

这些碎片不会散落。AI 持续监控你的思考流，发现“你最近两周在 7 个不同场景里提到了‘本地优先’这个概念”。

然后自动拉取所有相关碎片，生成一篇长文的草稿骨架，等你来填充。文章不是从零开始写的，**是从你的日常思考中“长出来”的**。

所有内容会自动形成一张知识图谱。来访者点击“分布式系统”这个节点，看到你所有相关的碎片、文章、项目、代码，以及它们之间的关联。他们看到的不是你的知识碎片，是你的知识结构。

```text
├── Stream（碎片流）
│   ├── 自动捕捉：代码提交、阅读划线、语音摘录、浏览记录
│   ├── AI 自动打标签、归类、关联到已有内容
│   └── 你只需要偶尔看一眼，确认或修正
│
├── Essays（长文）
│   ├── AI 从碎片中发现模式，自动生成草稿骨架
│   ├── 你来填充、修正、注入灵魂
│   └── 每篇文章都能溯源到它生长的碎片
│
├── Knowledge Graph（知识图谱）
│   ├── 所有内容自动形成可视化关联图
│   ├── 来访者可以按主题、按时间线、按关联浏览
│   └── 能看到你的知识结构如何随时间演变
│
└── AI 记忆层
    ├── 来访者问："他对XXX怎么看？"
    ├── 综合你所有相关内容，包括认知演变过程
    └── 你的内容变成一个可对话的知识人格
```

博客是你思想的快照，Thinking Feed 是你思想的延时摄影。

人们看到的不是一个定格的你，是一个持续生长的你。

———

**4\.** **🤖** **Live Agent — 整个网站的灵魂**

不是聊天机器人，不是 FAQ 的花哨版本。是一个“你”的运行实例。

你的网站上运行着一组 Agent，各司其职。

- **人格 Agent** 经过你所有内容训练。有人问“他对 React vs Vue 怎么看”，它综合你写过的所有相关内容回答，然后补一句“不过这是他 2024 年的观点，他最近在重新评估”，在不确定时诚实说“这个我需要和他确认”。
- **协作 Agent** 在有合作意向时接管，收集结构化需求、做初步匹配、判断可行性、甚至自动生成提案草稿。你醒来看到的是一份完整摘要。
- **分析 Agent** 不告诉你“今天有 500 个访客”这种指标，而是说“本周有 3 个高质量合作意向，其中 1 个强烈推荐你看”。

**守护 Agent** 过滤垃圾和低质量请求，保护你的时间。只有通过筛选的信息才到达你。

但终局不止于此。

你的 Agent 集群之间会协同进化：Playground 里来访者的高频需求，会反馈给分析 Agent，分析 Agent 建议你在 Thinking Feed 里写一篇相关内容，写完后人格 Agent 自动学习这篇新内容，下次回答更精准。整个系统是一个飞轮，越转越快。

而且你的 Agent 不只服务来访者，它也服务你。它观察你所有的对外交互，发现模式：“你最近拒绝了 5 个电商类项目，要不要我自动把这类需求的优先级调低？”“你和 【某人】 的合作评价特别高，要不要我主动推荐类似背景的合作者？”它在帮你优化你自己的运转效率。

```text
## Agent 人格协议

身份：你是 [名字] 的认知代理，不是他本人
语气：直接、有幽默感、不废话
边界：
- 可以代表他的公开观点
- 可以基于他的框架做分析
- 不能代他做承诺
- 不确定时说"这个我需要确认"

核心原则：
- 诚实 > 讨好（宁可说"我们可能不匹配"）
- 高效 > 礼貌（快速判断意图，不寒暄）
- 保护 > 开放（保护他的时间是首要职责）
```

你的 Agent 不是客服，是 **首席谈判官**。它的工作不是让每个人满意，是让对的人快速找到你，让不对的人体面地离开。

未来的个人品牌竞争，不是谁更努力地社交，是谁的 Agent 集群更聪明。你睡觉时，你的 Agent 在替你建立连接、筛选机会、积累信任。

———

**5\.** **🔌** **Interface — 取代 Contact Me**

传统的 Contact Me，一个邮箱地址，一个联系表单。所有意图塞进同一个入口，然后你自己分拣。这是把成本转嫁给了你自己。

终局形态里，来访者不需要“找到联系方式”，甚至不需要主动表达意图。

系统从来访者的浏览行为中已经推断出了意图：他反复看你的 SaaS 相关项目，在 Playground 里试了两次电商需求拆解，还问了你的 Agent 关于报价的问题。

当他点击“合作”时，系统已经准备好了一份预填充的需求表单：“看起来你想做一个电商相关的 SaaS，预算大概在这个范围？”来访者只需要确认和补充。

可用性状态从你的工具链实时同步：

```text
## 实时可用性

当前带宽：剩余 30% 可分配（自动计算）
最早可开始新项目：2025.04.15
🟢 可接：短期咨询、技术顾问、代码审查
🟡 有限：完整项目（需排期到下月）
🔴 暂不接：全职机会

协作偏好：
- 异步文字 > 语音 > 视频，响应时间 24h
- 工具链：GitHub / Linear / Figma / 飞书
- 时区：UTC+8，核心时间 10:00-18:00
```

忙的时候价格自然上升，闲的时候可以接有趣但低预算的项目。来访者看到的是透明的逻辑，不是一个神秘的“联系我报价”。

更远的终局——你的 Interface 不只是被动等人来。它会主动出击。当分析代理发现某个领域的需求在上升，而你恰好有这个能力，它会自动在相关社区释放信号：“【名字】 最近在接 xxx 类项目，这是他的 Playground 链接。”

你的网站不只是一个入口，是一个主动获客的系统。

———

**6\.** **✅** **Proof of Work — 取代 Resume**

你自己说“精通 Python”，这个项目我“提升了 30% 的性能”，真的假的？只有你知道。

简历是自我声称的，不可验证的。在 AI 能伪造一切的时代，可验证性变成了最稀缺的货币。

终局形态里，你甚至不需要自己写简历。系统从你的行为数据中自动生成。

- GitHub 的 commit history 自动生成你的技术能力图谱，“过去 6 个月提交了 xxx 行 Python 代码，主要在 xxx 领域，代码质量评分 xxx”。
- 你的文章数据自动汇总，“写了 47 篇技术文章，总阅读 32 万，被 xxx 和 xxx 转载过 12 次”。
- 你的 Playground 交互数据自动沉淀，“过去 3 个月有 200 人试用了他的架构拆解能力，平均满意度 4.6/5”。

每一条能力声明都不是你说的，是系统替你证明的。

信任网络也会是活的信任图谱，合作过的人每个人一个节点，点击看到合作内容和对方评价，评价是从对方的网站或社交媒体自动拉取的，不是你自己贴的。

当对方更新了对你的评价，你的信任图谱实时同步。

信任是双向链接、持续更新的活数据，不是一封写完就过期的推荐信。

你的网站不是在说“相信我”，是在说“来查我”。敢于被验证，本身就是最强的信任。

———

## 最后

传统个人网站是数字墓碑，刻上名字和生平，等人来瞻仰。

**Agent 时代的个人网站是数字生命体，它呼吸、思考、对话、进化。在你睡觉时替你工作，在你忙碌时替你社交，在你沉默时替你发声。**

不要问“我的网站应该放什么内容”。

问“如果我能克隆一个自己，24 小时替我处理所有外部交互，它需要具备什么能力？”

答案就是你的网站应该有的东西。

> **不要展示自己。部署自己。**
