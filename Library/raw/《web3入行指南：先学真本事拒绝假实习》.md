# 《web3入行指南：先学真本事拒绝假实习》

一、前言

我们进入web3工作之前，大多需要实习来获得行业经验，而获得实习机会也需要我们有充足的知识储备来应对面试和满足基本工作能力。web3行业与传统行业在实习和就业方面最大的区别就是较为缺乏完善并普及的培养体系，而这段既没有实习经历也没有知识储备的时间需要我们自己去找学习资源、去参加学习小组，有了一定的知识储备再去当大使等入门岗位，进而扎根在web3行业。

二、我的币圈实习经验

我是2020年看到群里有人做交易所推广进入币圈的，大大小小接触了几十个项目，有好项目，也有虚拟盘，比如耳熟能详大爷大妈都在挖的pi币等。遇到过连工资都找理由打折扣的项目方、也遇到过连团队内部抽奖几u都搞内定的老板。币圈工作水更深，对于像我们这样的小白来说真的容易上当受骗，传统行业被骗还可以打官司，币圈可没有这种兜底待遇，这让我意识到一定要提升自己的能力去有门槛的公司。

三、学习真本事才是进入web3的第一步

坦白地说，Web3的学习资源是非常零散的，单纯看web3的书籍和纪录片远远不够，能找到相对完整且一直更新的学习内容不容易。

我在这里推荐Web3实习计划，我去年第一次报名并没有通过录取，但也让我知道了这是一个宁缺毋滥、真心办事的好组织，于是认真准备了今年四月的学习课程，实习计划是由 LXDAO 与 ETHPanda 联合发起，一个面向高校学生与 Web3 新人的成长型入门项目，免费提供系统学习、实战训练、岗位对接与社区陪伴，这是他们的详情介绍：

四、结合亲身经历展示为什么推荐

![](https://pbs.twimg.com/media/HJGRJqkbUAAOAPR.png)

每天在平台上会有任务，这些任务是循序渐进的，确保每个人都能够按照自己进度去完成一个自己想要做的项目。图三是学员自己跑出来的成果，而类似的在微信群里很多，每个学员都有收获，共同学习、共同创造的友好氛围

![](https://pbs.twimg.com/media/HJGQlfCbcAAbs9c.png)
