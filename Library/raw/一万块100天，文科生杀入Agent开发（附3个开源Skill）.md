# X 上的 李韭二：”一万块100天，文科生杀入Agent开发（附3个开源Skill）” / X

https://x.com/li9292/status/2034563032265957798?s=20

100天前，我连终端是什么都不知道。

100天后，我坐在Agent开发者的嘉宾席上。

一万块。一台Mac mini，三个月的AI订阅。

没有培训班，没有导师，没有科班背景。

你觉得我在装？往下看。

## 12月：心虚

我跟ChatGPT说过一句话："我觉得我一直心虚。"

不是谦虚，是真的心虚。

看别人写代码，觉得那是另一个物种的技能。

我是学文科的，写过最多的"代码"是Excel公式。

但2025年底，焦虑逼到墙角了。

AI把内容创作的门槛踩平了，我引以为傲的写作能力突然贬值。

不转型，死路一条。

我给自己定了个计划：100天，每天至少6小时，学编程。

买了台Mac mini，下载了Claude Code。

第一天，我连终端是什么都不知道。

问ChatGPT："Agent是什么？"

它给我打了个比方

就像你开了个柠檬水摊，你是老板，AI是员工，工具是榨汁机，记忆是账本。

我靠，这我能理解。

然后我去GitHub fork了一个圣诞树项目，作为圣诞礼物送给我女朋友。

3D粒子特效，手势交互。

注意，是fork的，不是我写的。我只是改了改颜色，加了几张照片。

但那是我人生中第一次，在浏览器里看到自己"改过"的东西跑起来了。

那种感觉，比什么鸡汤都管用。

## 1月上旬：GitHub是我的学校

我开始疯了一样造东西。

把GitHub当学校。别人的开源项目是教材，fork下来读代码。

自己的原创项目是作业，写完交上去。

一天一个项目，停不下来：

1⃣ scratch-card-habit——刮刮卡习惯打卡，我的第一个从零开始的项目

2⃣ wulin-town——武林外传主题小镇，踩了一堆npm依赖的坑，写了个PITFALLS.md记录了10条教训

3⃣ ohvibecoding——多语言网站，学了SEO和国际化

每天6到8小时泡在里面。

Claude Code成了我的结对编程伙伴。

我问它什么是MCP

它说："想象你在装修房子。Agent是项目经理，Tool是电钻和锤子，MCP是让项目经理能指挥所有工具的通信协议。"

文科生就吃这套。别给我看文档，给我讲故事。

踩坑？太多了。npm报错看不懂，Git推不上去，Vercel部署到一半崩了。

但每个坑我都记下来了。后来这些坑变成了我的第一个Claude Code Skill——一个自动记录踩坑日志的工具。

把失败变成资产。

## 1月中旬：我不是程序员，但我不需要是

有一天ChatGPT跟我说了一句话，我愣了半天：

"你不是做编程，而是在构建自己的代码杠杆。"

我愣了半天。然后回头看了看自己写的那些作业。

我写的代码确实烂。变量命名乱七八糟，结构也不优雅。

但有一个东西是对的：我写的SKILL.md，Agent能读懂，人也能读懂。

因为我干了十几年的活就是这个:

把复杂的东西翻译成人话。

代码是新学的，翻译是老本行。

## 1月底到2月：从抄作业到出题

1月下旬，我fork了call-me和openclaw。

call-me是一个让Claude Code给你打电话的MCP插件。我拆开看了代码，学会了WebSocket和音频处理是怎么回事。

openclaw是一个完整的Agent平台。我学到很多。

关键转折发生在2月12号。

那天我没有fork任何东西。

我打开编辑器，从零开始写了一个项目：memx-memory。

Agent的记忆系统。向量嵌入，维度匹配，记忆分层。

这些词在100天前对我来说跟火星语一样。

但我写出来了。能跑。

后来又迭代了两版：

memx → epro-memory → 最后合进了openclaw的memory-core。

三个版本，每一版都比上一版成熟。

这意味着什么？

我从"读别人代码学东西"变成了"给别人的平台写工具"。

我终于从抄作业的，变成出题的了。
