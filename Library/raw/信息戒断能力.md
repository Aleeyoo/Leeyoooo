# Post by @Crypto_Chanshi on X

https://x.com/Crypto_Chanshi/status/2029098643836547117?s=20

纳瓦尔曾在一个访谈中提出一个独特的观点，叫信息戒断能力。

他觉得未来十年，人与人之间的差距不是谁学得多、谁的信息路子更广。因为在AI面前，所有人都是信息贫民。

真正的、最大的差距在于，谁有能力对信息say no。

“大多数人把学习当成一种拖延形式，他们消费信息来获得‘我在进步’的幻觉，同时逃避那件真正能改变人生的事。”

这是整场访谈里最让人反思的一段，因为直接捅穿了知识付费的幻觉：

你以为自己在充电，其实你在自我麻醉。

收藏文章、保存截图、购买课程、刷深度长文...…你以为这是在努力。

但真相其实是，你在用信息的“量”，来逃避行动的“质”。

那件你一直拖着不做的事，比如写某篇文章、启动某个项目、打某个电话、尝试联系某个人，也许才是你人生的唯一解药。

归根结底，行动才是正道。

信息（知识）不是资产，只有被你用上的信息（知识），才是资产。
