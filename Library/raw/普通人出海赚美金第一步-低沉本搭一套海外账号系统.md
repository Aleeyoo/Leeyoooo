# X 上的 veyhon：”普通人出海赚美金第一步：低沉本搭一套海外账号系统 ” / X

https://x.com/veyhon/status/2057116586880925924?s=20

## 1\. 先说结论

最近 giffgaff 在中文 X 圈突然变火，很多人开始研究怎么买英国 SIM 卡，甚至去电商平台搜索各种黑话。经过这两天中文推特圈的洗礼，大家都已经知道旧教程里那种免费申请、直邮中国大陆或香港的路径不能照抄；如果还能免费直邮，也不会有那么多人去京东搜索「英国信封」。

所以这篇文章不再重复讲「怎么免费申请 giffgaff」。买到英国号以后，还要继续处理三件事：ChatGPT、Claude、Cursor 能不能持续扣费，X 创作者收益能不能从 X 接到 Stripe Express，Stripe Express 里的 payout 能不能再进 Wise 或其他可用账户。

对中国大陆普通人来说，整套配置先检查四个位置：验证码、AI 扣费、Stripe payout、Wise 入账。只盯着 giffgaff + Wise，容易以为拿到两个工具就结束了，结果卡在账单地址、Stripe Express 或 Wise 币种账户详情上。

比如，giffgaff 官方规则里有 6 个月 inactive 停号问题，Wise 官方说明里有 Stripe 入账币种和账户详情限制，公开 X 收益教程会把 Stripe Express 当成核心步骤，OpenAI 和 Claude 的官方帮助页也列出了银行拒付、3DS、账单地址、地区或卡片发行地这些付款失败原因。下面这张网页截图拼图，只用来说明要提前检查哪些环节，不代表每个人都会逐个踩坑。

![图像](https://pbs.twimg.com/media/HIxWq9YaQAAsMey?format=jpg&name=large)

这篇文章先不摊大饼，只讲两件事：AI 工具持续订阅，X 创作者收益收款。海外工具可以以后慢慢补，第一版先把手机号、付款、收款、恢复方式这四件事配到够用。

## 2\. 最小配置是什么

这里说的「不去香港」，意思是默认不依赖香港线下开户、香港手机号、港卡或当面办理材料。我们只看中国大陆普通人在家里更容易拿到、也更容易维护的东西：长期邮箱、能保号的海外手机号、Wise、已有 Visa / Mastercard、App Store / Google Play，以及一个密码管理器或离线表格，用来保存账号、手机号、2FA 备用码、付款方式和下次保号日期。

AI 订阅先用已有银行卡测试，失败时再切 App Store / Google Play 或备用卡；X 收益则尽早检查 Monetization / Creator Studio 入口，没达标就先把 Premium、邮箱、2FA、账号状态这些基础项补齐，达标后从 X 进入 Stripe Express，再用 Wise 的可用账户详情测试小额 payout。这样做的好处是每一步都能验证，不用一开始就买一堆卡、开一堆账户。

## 3\. giffgaff 和 Wise 分别解决什么

giffgaff 主要负责验证和恢复。它能用来注册账号、接收验证码、绑定恢复方式，也能在一些海外平台上补足手机号这一环。现在如果从电商平台或转寄渠道买「英国信封」，别只看价格，至少要问清楚四件事：卡是否未激活，能不能绑定自己的邮箱和 giffgaff app，是否可以正常充值或购买套餐，人在中国大陆能不能接短信。

giffgaff 后续要管的是保号。官方帮助页写得很清楚，如果 SIM 在 6 个月内没有使用，号码可能被视为 inactive 并进入停用流程。只拿它接验证码的人，最容易忘记隔几个月让号码产生一次有效使用记录，所以建议从激活当天就设置 5 个月一次的提醒。

![图像](https://pbs.twimg.com/media/HIxW04vbQAAAlGG?format=png&name=large)

Wise 主要负责跨境资金入口。它对中国大陆用户已经开放了身份证验证，这让普通人可以比较轻地获得多币种账户能力，但这不等于人民币直接充值、所有币种入金、所有 Stripe payout 都没有限制。

尤其是 X 收益这条线，Wise 能不能接 Stripe，取决于你使用的账户详情和币种。Wise 官方帮助中心明确说，Wise 可以连接 Stripe 收款，但只适用于部分账户信息和币种；例如 CAD、CHF、DKK、HKD、JPY、NZD、SGD、USD 等可以接收，AED、AUD、CNY、CZK、ILS、UGX 等不行。操作上不要默认所有 Wise 币种都能用，先在 Wise 里开好可用的账户详情，再去 Stripe Express 里填 payout。

![图像](https://pbs.twimg.com/media/HIxYdfKaIAAPbgA?format=jpg&name=large)

## 4\. AI 订阅怎么做

AI 订阅最适合先解决，因为它最直接，也最容易测试。ChatGPT 可以先试网页订阅，失败再试 App Store / Google Play；Claude 重点看卡片、账单地址和 3DS 能不能过；Cursor 则从 billing portal 更新付款方式，确认同一张卡能不能完成扣费。三个工具分开测，入口不一样，失败原因也不一定一样。

OpenAI 官方多币种 billing 页面说明，ChatGPT 网页订阅支持信用卡 / 借记卡，部分地区支持本地支付方式，移动端订阅则由 App Store 或 Google Play 管理。网页订阅和应用商店订阅走两条路径，网页扣费失败时，可以先测试应用商店订阅，再考虑要不要准备新的卡。

OpenAI 和 Claude 的付款失败说明基本指向同一类问题：发卡行拒绝交易、余额不足、账单地址不匹配、3DS 验证失败、地区或卡片发行地不支持。对普通人来说，最省事的做法是先用已有卡测试，再准备一张备用卡或应用商店订阅路径。AI 工具已经是日常工作工具的人，至少要提前知道第二条付款路在哪里。

## 5\. X 收益怎么做

X 收益这条线要早看入口，不要等账号已经达标了才临时补材料。现在就去 X Monetization / Creator Studio 看自己差哪一项：Premium、粉丝、曝光、邮箱、2FA、账号状态，能补的先补掉；等入口允许继续设置 payout 时，从 X 里面进入 Stripe Express，不要自己单独去 Stripe 官网新开一个账户。

收款账户提前在 Wise 里准备，优先用 Wise 官方说明里能接 Stripe 的币种账户详情。Stripe Express、Wise、税务表格里的姓名、拼音、账户持有人信息不要前后乱跳；遇到 W-8BEN，就按自己的真实税务身份填写。第一次 payout 不要急着上大额，先用小额确认 Stripe 到 Wise 能不能到账。

## 6\. giffgaff + Wise 之外，还有哪些替代

手机号这边，giffgaff 适合想要低成本英国号的人，但下单前要确认寄送、激活、充值、漫游接码和 6 个月 inactive 规则；Ultra Mobile PayGo 更偏美国号方案，月租通常高于 giffgaff，境外使用前要确认漫游接码；Tello 或其他美国低价号适合想要 eSIM 或灵活套餐的人，但境外激活和接码稳定性需要实测；国内手机号和备用邮箱则放在恢复兜底层，不能替代海外平台要求的海外号码。

付款这边，先试已有 Visa / Mastercard，因为成本最低、验证最快；网页订阅失败，再走 App Store / Google Play；AI 工具已经是生产力基础的人，可以提前准备一张备用国际卡，但没必要一开始就堆工具。

收款这边，Wise 适合先拿来测试 Stripe 入账。它可以做多币种账户、部分 Stripe 入账测试和跨境转账测试；以后如果有更稳定的银行账户，再把 Wise 放到收款路径里做中转或备用。

## 7\. 最小步骤方案

如果这篇文章只给一套方案，我会按这个顺序做：先准备邮箱体系，包括主邮箱、备用邮箱、密码管理器和 2FA 备用码；再准备手机号，giffgaff 或其他可长期保号的海外号都可以，但下单前要确认卡未激活、可自己绑定邮箱、可充值、可在中国大陆接短信，并设置 5 个月一次的保号提醒；然后开 Wise，完成实名验证，拿到自己能用的币种账户详情，并测试小额转账；接着解决 AI 订阅，用已有 Visa / Mastercard 分别测试 ChatGPT、Claude、Cursor，失败再走 App Store / Google Play 或备用卡；最后处理 X 收益，先检查 Monetization / Creator Studio 入口，补齐 Premium、邮箱、2FA 和账号状态，达标后按 X -> Stripe Express -> Wise 的路径测试 payout。

这套顺序里，每一步都有验收动作：手机号收一条短信，AI 工具完成一次扣费，Wise 做一次小额入账，X 收益用小额 payout 测到账。AI 订阅最快验证，X 收益放在最后，是因为它最依赖平台资格和 Stripe payout 流程；但入口要尽早看，能提前补的账号条件不要拖到临门一脚。

## 8\. 后续只维护两件事

AI 订阅不用专门每月检查，扣费失败你自然会知道。更容易被忘掉、且忘掉以后很麻烦的，是海外手机号保号和恢复资料保存。giffgaff 这类号，可以每 5 个月提醒一次，确认能登录、能接短信、保号动作已经完成；邮箱、2FA 备用码、Wise 登录方式、X 登录方式，则集中记录到密码管理器或离线表格里。

离线记录表不用复杂，记录账号名称、登录邮箱、绑定手机号、付款方式、2FA 备用码存放位置、下次保号 / 续费日期、出问题时的备用路径就够了。普通人做这套配置，麻烦通常不在工具本身，而在三个月后忘了当时怎么配的。

## 9\. 最后压成四个问题

giffgaff 火起来，说明国内普通人对海外数字入口有真实需求。买英国号只是第一步，后面还要把付款、收款和恢复方式接上。

AI 订阅，先解决付款和续费；X 收益，按 X -> Stripe Express -> Wise 的路径，把账号资格、Stripe 流程和 Wise 收款账户详情接起来。以后每新增一个海外工具，都按四个问题检查一遍：我怎么登录、我怎么付款、我怎么收款、出问题时我怎么恢复。四个问题答清楚，再决定是否需要新增手机号、Wise、银行卡或其他付款方式。
