# 一、先破除一个最贵的误区

很多人一听"提高客单价"，第一反应就是：涨价、满减、推销。

这是把简单问题做复杂了。先看公式：

销售额 = 流量 × 转化率 × 客单价 × 复购率 客单价 = 每单购买件数 × 单件成交价 利润 = 客单价 × 毛利率 − 获客成本 − 履约/售后成本

注意最后一行——**客单价上涨 ≠ 利润上涨。**

折扣、赠品、履约成本会把毛利吃掉。很多商家死在这个"假增长"幻觉里：GMV 涨了，利润反而薄了。

所以这篇讲的"让顾客多花钱"，标准只有一个：

**净利润型增长**，不是后悔式消费。

顺便说给超级个体（咨询、教练、博主、设计、陪跑）

你可能没有"购物车"，但你一样卡在客单价上。而且你比商家更难——**你不敢让客户多花钱。** 根子是这 5 个心理卡点：

![图像](https://pbs.twimg.com/media/HI6JvWuaoAAgfGg?format=png&name=large)

记住底层逻辑：**高客单不是"贵"。** 贵 = 价格高但价值低；高客单 = 价格高，同时价值、确定性、交付密度、风险控制都更高。

# 二、6 个被验证过的杠杆（每个都有真实数字）

提高客单价不是一个大招，是 6 个可以分别去拧的螺丝。

## 杠杆 1：产品分级——把"消费者剩余"赚回来

顾客愿意付 200 元，你只卖 99 元，中间那块价值就白送了。**产品分级**让高支付意愿的人主动选更高档。

做法：

把产品做成 **入门款 / 标准款（主推）/ 高配款**。

高配不是多给点数量，而是加服务、加容量、加保障、加稀缺性。

展示顺序：先亮高配锚点，再推主推款，最后保底入门款。

> 验证：报价给三档的软件公司，把 CRM 和数据分析工具组合销售，**成交率提升 42%**；阶梯折扣让采购量**提升 30% 以上**。（简道云）

## 杠杆 2：场景组合——别靠感觉搭套餐，让数据告诉你

最自然的加购不是"猜你喜欢"，而是"你要完成这件事，还差这几样"。

开头那家零食店就是靠这个——**购物篮分析**。

顾客其实已经在订单里告诉你哪些商品该放一起卖，你要做的只是把它找出来。

> 验证：零食店靠购物篮分析重组组合，客单价 **68 → 86.4 元（+27%）**，毛利额 +19%。（搜狐 / CDA）

落地动作：

导出近 30–90 天订单（只留订单 ID + SKU）→ 找高置信度、高提升度的组合 → **先做 3–5 个组合**，别一次上太多 → 每个组合写清"解决什么场景"（早餐组合、露营一套、护肤三件套）。

## 杠杆 3：门槛机制——满减不是打折，是"差一点就够得着"的诱饵

满 199 包邮、满 299 送赠品，利用的是**损失规避**：不凑单就觉得亏。

关键在门槛**不能拍脑袋**。太高顾客直接放弃，太低等于白送。

> 验证：宠物店满就送，门槛卡在顾客够得着的位置，**客单价相对 +50%**，下单买家 +20%。（麦象网）

推荐公式：

免邮 / 满赠门槛 = 当前 AOV × 1.2 ~ 1.4 赠品 = 顾客认识、想要、低成本、高感知价值的东西 页面必须明确提示："还差 X 元可获得 Y"

## 杠杆 4：加购触点——购物车是利润最密集的地方

购物车整体放弃率约 **69.9%**，一个重要原因是"意外运费"。但有意思的是——**顾客讨厌付运费，却不讨厌为了免运费多买一件。**

所以加购的位置很关键，要放在顾客最容易接受的地方：

原则：强相关、能一键加购、不打断主购买流程、默认不勾选。（来源：Rebuy 17 tactics、Social Snowball）

## 杠杆 5：复购与升级——老客是最该被"多卖"的人

信任已经建立的老客，是升单成功率最高的群体。客单价提升不该只发生在第一次购买，要分布在整个生命周期。

> 验证：忠诚客户的平均购买金额比新客户高 **20%–40%**；个性化节日推送让单笔客单价 **+15%**。（简道云）

落地：

建客户标签（高频 / 高价 / 价格敏感 / 沉睡 / 老客）→ 不同标签配不同推荐和权益 → 对生日、补货周期做自动提醒 → 用会员等级、积分、订阅把"一次交易"变成"长期关系"。

## 杠杆 6：价格心理——顾客判断的不是"贵不贵"，是"值不值"

价格不是一个数字，是一个**比较系统**。顾客愿不愿意多花，取决于他拿这个价格跟什么比。

四个可直接测的心理动作：

- **锚定**：先展示高配/套装，再展示基础款，抬高心理基准。
- **三档定价**：让中间档成为默认选择（多数人选推荐档）。
- **99 尾数**：非奢侈品可测试。
- **分期 / 储值**：高价商品把"一次性痛感"拆成小单位。

# 三、超级个体怎么落地

上面 6 个杠杆是给"有货盘"的人。如果你是一个人接活的咨询/教练/陪跑，翻译过来就是这套：

## 1\. 先问价值，再报价

客户一问价就报数字，是超级个体最大的错误。**先不报价，先问价值**：

1\. 你最想解决的具体问题是什么？ 2. 如果 3 个月 / 12 个月后还没解决，会损失什么？ 3. 这个问题现在让你少赚 / 浪费 / 错过了多少？ 4. 如果解决了，这个结果对你一年值多少钱？

把"想要服务"变成"看见代价"，你的报价才有锚点。

## 2\. 把一个价格变成三档

一个价格 → 客户做"买不买你"的二元判断（容易 No）。 三档价格 → 客户做"选哪一档"的判断（默认会买）。这就是杠杆 1 在服务业的用法。

方案 A：

看清问题→ 诊断 + 问题地图 + 三条优先动作（中档的 50%-60%）

方案 B：

跑通结果（推荐）→ 诊断 + 方案 + 每周陪跑 + 复盘（你真正想卖的价）

方案 C：

系统放大→ B 全部 + 体系搭建 + 优先答疑（B 的 150%-180%，负责锚定）

别叫"基础版/标准版/高级版"，用结果命名：看清版 / 跑通版 / 放大版。

## 3\. 自然加购，把拒绝权还给客户

满足这 4 个条件才推荐升级，否则别硬推：

① 客户表达了更大目标

② 当前方案覆盖不了

③ 升级能明显降风险

④ 客户有拒绝权。

一套不冒犯的话术（直接抄）：

我可以直接给你一个比较真实的建议吗？

你现在最想要的不是再学一套方法，而是把转化跑起来，对吗？

A 方案能帮你看清问题，但它不含后续修改和复盘——你执行力不稳的话，结果会不确定。

所以按你的目标，我更建议 B 方案，它贵一些，但更匹配你要的结果。

当然这不是必须选，你也可以先从 A 开始，做完诊断再决定要不要升级。

核心心法：**你越给台阶，客户越敢往上选。**

# 四、最小可执行：7 天落地清单

第 1 天：导出近 30 天订单，算 AOV、毛利、二件以上订单占比。 第 2 天：找出 Top 20 SKU，标注入口品 / 利润品 / 配件品 / 复购品。 第 3 天：做 5 个强相关组合，每个写明"解决什么场景"。 第 4 天：设一个免邮 / 满赠门槛，门槛 = 当前 AOV × 1.2~1.4。 第 5 天：在详情页、购物车、客服话术里加入同一套组合推荐。 第 6 天：上线 A/B 测试，只测一个变量。 第 7 天：看 AOV、转化率、毛利率、客诉，只留净利润提升的方案。

（超级个体版：第 1-2 天列出 5 个客户最贵的问题并量化 → 第 3-4 天写三档报价 + 报价页 → 第 5-7 天找 10 个客户做价值访谈，记录他选哪档、卡在哪。）

# 五、红线：哪些钱不能赚

客单价涨上去，信任不能塌。守住这几条：

1. 不向**不满意 / 有流失风险**的客户升单——先解决体验，再谈追加。
2. 不推**无关商品**——推荐越随机，顾客越觉得你在割他。
3. 不靠**制造焦虑**逼单——焦虑能短期抬客单，但只有信任能抬复购。
4. 不**只看 GMV**——亏钱换来的高客单是假增长。
5. （超级个体）客户**只需要基础执行**，就别硬卖复杂方案。

推荐越聪明，顾客越觉得你在帮他； 推荐越随机，顾客越觉得你在割他。 真正能长期涨价的人，靠的是匹配度，不是压迫感。

# 写在最后

让顾客多花钱，从来不是话术问题，是**结构问题**。

那家零食店没涨价，只重排了组合，客单价就涨了 27%；那家宠物店没换货，只把门槛卡对了，客单价就涨了 50%。

他们做的不是"劝顾客买贵"，是**让顾客觉得：我本来就该买这一套。**

你不是在多卖一个商品，而是在帮他少一次麻烦、多一个确定性。
