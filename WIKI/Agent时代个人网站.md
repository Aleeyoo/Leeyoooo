# Agent时代个人网站

> [!abstract]- AI 摘要
> 传统个人网站是贴在互联网上的名片，Agent 时代的个人网站是你部署到互联网上的一个活的自己——能对话、能干活、能替你在睡觉时筛掉 90% 的噪音。核心转变：不是在"展示自己"，而是在"部署自己"。

## 扫读

> [!tip] 💡 一句话
> 传统网站是货架（你摆信息，别人看），Agent 时代反过来了——来访者带着意图来，你的系统主动理解、服务、对接，24 小时替你工作。

> [!important] 📌 关键结论
> - 未来最贵的不是技能清单，而是"认知源代码"——技能是编译后的产物(所有人都看到同样的输出)，源代码才是不可替代的东西
> - 六大模块的终局形态：My OS(取代 About)、Playground(取代 Portfolio)、Thinking Feed(取代 Blog)、Live Agent(整个网站的灵魂)、Interface(取代 Contact)、Proof of Work(取代 Resume)
> - 信任变成可验证的活数据：每一条能力声明都不是你说的，是系统替你证明的——"不要相信我，来查我"

> [!quote] 🎬 可行动项
> - 思考你的"认知源代码"是什么——你的思维模型、决策框架、独特视角，而非技能清单
> - 从 Portfolio（截图+描述）升级到 Playground（让来访者直接体验你的能力运转）
> - 定义你的 Agent 人格协议：身份、语气、边界、核心原则

  传统网站 = 名词（页面、文字）→ 被动等待

  ② Playground：来访者上传素材→当场输出你的能力展示→主动生成合作提案
  ③ Thinking Feed：无需手动写，日常行为自动捕捉→AI发现模式→长文自动"长出来"
  ④ Live Agent：人格Agent+协作Agent+分析Agent+守护Agent，协同进化形成飞轮
  ⑤ Interface：系统主动推断意图，实时同步可用性状态，主动获客

### 关键引述

> 传统网站的每个模块都是名词：一个页面、一堆文字。终局形态的每个模块都是动词：一个过程、一个系统、一个持续运行的东西。你的网站不是一个地方。它是一个过程。

> 作品集是尸检报告，对已经完成的东西做事后分析。Playground 是活体演示，让人直接感受你的能力在运转。

> 博客是你思想的快照，Thinking Feed 是你思想的延时摄影。人们看到的不是一个定格的你，是一个持续生长的你。

> 你的 Agent 不是客服，是首席谈判官。它的工作不是让每个人满意，是让对的人快速找到你，让不对的人体面地离开。

### 局限与盲区

- **本文未覆盖**：具体的 Agent 网站技术实现方案（用什么框架、部署在哪、成本多少）；隐私和安全的实际边界（让 Agent 7x24 替你做决策的风险）；不同职业类型（程序员 vs 设计师 vs 咨询师）的网站差异设计；冷启动问题（没有数据积累时系统如何运转）
- **隐含假设**：来访者愿意与 Agent 互动而非直接联系本人；AI 能准确代表个人做出不损害声誉的决策；用户有足够的数据资产来训练 Agent 和生成内容
- **可能的反例**：高端 B2B 场景下客户可能更想要真人接触而非 Agent 过滤；某些行业（如法律、医疗）Agent 替人承诺可能带来法律风险；过度依赖 Agent 可能让个人品牌失去"人味"
