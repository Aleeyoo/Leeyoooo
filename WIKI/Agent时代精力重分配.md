# Agent时代精力重分配

> [!abstract]- AI 摘要
> AI Agent 时代，个人最优时间分配应从传统的 70%执行+30%思考迁移到 50%执行+50%思考，执行升级为编排式交付，思考升级为建立选择函数的判断系统。

---

## 扫读

> [!tip] 💡 一句话
> 当执行被 Agent 放大后，核心竞争力从“做得多”转向“判断准、系统强”，最优策略是将时间从低层执行重新分配到能改变执行质量的思考上。

> [!important] 📌 关键结论
> - 原 70%执行+30%思考模型失效：Agent 压缩了低层执行，瓶颈从执行端向上游判断端迁移
> - 五类人中，50% Make + 50% Think 是未来三年最佳平衡点，兼具真实交付和系统升级
> - Make 的新定义是三层结构：亲手执行 → Agent辅助执行 → Agent自主驱动的可复用系统，第三层产生复利
> - Think 的新目标是建立“选择函数”——在一堆可能性中选出值得投入的那一个
> - 个人四个新核心能力：意图设计、工作流设计、质量判定、品味和责任心

> [!quote] 🎬 可行动项
> - 每天保留 60-90 分钟深度 Think block，处理最上游的判断问题
> - 每天执行尽量 Agent-first：先问“哪部分应由 Agent 先跑一版”
> - 每周划分三类时间：Think block + Make block + Workflow block（占 10-20%）
> - 每月用 1-2 天做系统级复盘：哪些任务应交 Agent、哪些 workflow 应产品化、哪些 Think 其实是拖延

### 关键引述


> 未来 3 年，最优的个人时间分配，会从过去的 70% Make + 30% Think，逐渐迁移到 50% Make + 50% Think。

> 价值正在从“我会问 AI 一个问题”，进入“我能把一段工作改造成 AI 可以持续参与的系统”。

> Agent 时代，产出的单位不再只是“一个人一天能做多少事”，而是：一个人能设计多少可复用的高质量工作流。

> 想法会变得极其便宜。任何人都可以让 AI 生成 20 个产品方向、10 篇文章大纲、5 套技术方案。难点在于知道哪一个方向值得投入，哪一个方案会在现实里坏掉，哪一个输出虽然漂亮但不可信。

> AI Agent 时代，最危险的人未必是不会用 AI 的人，也可能是用 AI 加速旧工作方式的人。

### 局限与盲区


- 本文未覆盖：不同行业（如体力劳动、高度合规行业、创意艺术）的 Think/Make 比例差异很大，50/50 可能不通用。团队协作场景中的精力分配也未讨论。
- 隐含假设：假设读者有足够的自主权来重新设计自己的工作方式，忽略了组织结构、KPI 体系、管理层偏好等外部约束。假设 Agent 能力会持续线性提升。
- 可能的反例：初级从业者可能需要更多 Make 来积累领域判断力，过早提高 Think 比例可能适得其反。某些深度创造性工作（如数学研究）的 Think 比例本身就应远高于 50%。
