## 扫读

> [!tip] 💡 一句话
> GitHub 是全球最大的开源协作平台。AI 降低了写代码的门槛但没有消灭项目管理的需求，GitHub 是 Vibe Coder 迟早绕不开的基础设施。

> [!important] 📌 关键结论
> - Git 和 GitHub 的区别：Git 是本地版本管理工具（记录每一次修改），GitHub 是基于 Git 的在线协作平台（托管项目、展示项目、连接开发者），新手先用网页版 GitHub 就够了。
> - 判断项目靠不靠谱看四点：README 是否清楚（说明书）、Star 数是否足够（热度参考）、最近有没有更新（维护状态）、Issues 有没有人处理（活跃度）。
> - 下载项目的正确姿势：先看右侧有没有 Releases（正式打包版本），有就优先下载；没有再点绿色 Code 按钮 Download ZIP。

> [!quote] 🎬 可行动项
> - 今天注册 GitHub 账号，创建第一个仓库，Star 几个感兴趣的项目
> - 学会搜索：在搜索框搜"AI 视频剪辑"等感兴趣主题，按 Star 数排序
> - 本周下载几个 AI 工具的 Releases，看看别人怎么写 README
