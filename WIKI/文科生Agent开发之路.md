# 文科生Agent开发之路

> [!abstract]- AI 摘要
> 一个连终端都不知道是什么的文科生，用 100 天、一万块预算从零杀入 Agent 开发——从 fork 圣诞树项目改颜色，到从零写出 Agent 记忆系统（memx-memory），再到坐在 Agent 开发者嘉宾席上。核心经验：把失败变成资产，用文科生的翻译能力写出 Agent 和人能共同读懂的 SKILL.md。

## 扫读

> [!tip] 💡 一句话
> AI 时代编程的门槛已经被踩平——你不需要成为程序员，你需要的是构建"代码杠杆"：文科生的"翻译"能力（把复杂的东西变人话）恰恰是写高质量 SKILL.md 和 Agent 提示词的核心竞争力。

> [!important] 📌 关键结论
> - 学习路径三阶段：fork 别人的项目改着玩（建立"能跑"的正反馈）→ 把 GitHub 当学校（一天一个原创项目）→ 从抄作业到出题（从零写工具给别人的平台用）
> - 文科生特有的优势不是写代码，而是把复杂概念"翻译成人话"——这个能力在写 SKILL.md 和 Agent 提示词时是强大的差异化竞争力
> - 失败的资产化：每个踩过的坑（npm 报错、Git 推不上去、Vercel 部署崩溃）记录下来变成第一个 Claude Code Skill——一个自动记录踩坑日志的工具

> [!quote] 🎬 可行动项
> - 从 fork 一个简单开源项目开始，只改颜色/图片，先获得"跑起来了"的正反馈
> - 每天一个原创小项目（不管多小），把 GitHub 当学校——别人的开源项目是教材，自己的项目是作业
> - 把你踩过的每个坑写成 SKILL.md——你的失败经历对 Agent 来说就是操作手册
